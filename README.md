# equiTattoo

A mobile-first web app for tattoo artists: stock of needle cartridges and pigments, a shopping list,
tattoo records with photos and pigment batch tracking, and a public gallery with no personal data.

The app is being built. The full plan is in [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md), and
architecture decisions are in [docs/decisions/](docs/decisions/).

## Stack

Angular 22, Firebase (Firestore, Authentication, Cloud Storage, App Check, App Hosting), GitHub Actions.

## Requirements for local development

- Node.js 24 LTS
- Java JDK 21, for the Firebase Emulator Suite
- Firebase CLI

Setup instructions will be added here with the app itself.
