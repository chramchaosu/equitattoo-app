# 2. Node.js 24 LTS

Date: 2026-10-30. Status: accepted.

**Context.** Angular 22 accepts Node ^22.22.3, ^24.15.0 or ^26.0.0. The newest LTS is 26, but firebase-tools 15.34.2
depends on superstatic 10, which only accepts Node 20, 22 or 24.

**Decision.** Use Node 24 LTS on developer machines and in CI, and don't let `winget upgrade` move it to 26.

**Consequences.** All tools install with no engine warnings. Review this when superstatic supports Node 26.
